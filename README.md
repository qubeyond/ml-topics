# ML Topics — чек-лист

Статический сайт-чеклист по темам ML / DL / NLP / матеше. Без бэкенда и сборки —
чистый HTML/CSS/JS, хостится через GitHub Pages.

## Как это устроено

- `index.html` — вся логика: на главной карточки категорий, по клику — страница
  с чек-боксами. Роутинг через `#/id` (без перезагрузки страницы).
- `content/manifest.json` — список категорий: `{ id, file, title }`.
- `content/*.md` — сами чек-листы, один файл = одна карточка на главной.
- Отметки галочек хранятся в `localStorage` браузера (per-device, без сервера).

## Формат `content/*.md`

```md
# Название категории (необязательно, можно взять из manifest.json)

## Часть I. Заголовок группы
### I.1 Подзаголовок
- [ ] Текст темы
- [ ] Ещё тема с [ссылкой](https://example.com)

- [ ] I.2 Тема без подпунктов — тоже чекбокс, если стоит прямо под "## "
```

- `#` — заголовок категории.
- `##` — крупный раздел (как "Часть I/II/III" в исходных PDF).
- `###` — подраздел, код в его заголовке (`I.1`) задаётся руками один раз.
- `- [ ] текст` — пункт чек-листа **внутри** `###`-подраздела. Номер (`I.1.1`,
  `I.1.2`, ...) подставляется автоматически по порядку строк — писать его не
  нужно, а порядок пунктов можно менять местами свободно.
- `- [ ] код текст` — если пункт стоит прямо под `##` (без `###`) или нужен
  устойчивый номер (не зависящий от порядка) — код пишем руками сами, как
  раньше. Такой явный код всегда используется как есть, автонумерация его не
  трогает.
- Явный код (свой или подставленный автоматически) — это ключ, по которому
  сохраняется галочка в `localStorage`. Не смешивайте в одном подразделе
  пункты с явным кодом и без него — тогда автонумерация не столкнётся с
  ручной.
- `- [x] ...` — пункт, отмеченный по умолчанию (можно так проставить то, что
  уже знаешь).
- В тексте пункта работают `**жирный**`, `` `код` `` и `[текст](ссылка)`.

## Добавить новую категорию

1. Создать `content/my-topic.md` в этом формате.
2. Добавить строку в `content/manifest.json`: `{ "id": "my-topic", "file": "my-topic.md", "title": "My Topic" }`.
3. Закоммитить — новая карточка появится на главной сама.

## Локальный просмотр

`fetch()` не работает с `file://`, поэтому нужен локальный сервер:

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```
